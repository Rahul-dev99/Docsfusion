# DocsFusion Upload Workflow

## Current Status

The initial upload workflow is implemented.

## Supported File Types

- PDF
- JPG
- JPEG
- PNG
- DOCX
- XLSX
- XLS

## Current Features

- Browse files
- Multiple file selection
- File type validation
- File size validation
- Duplicate detection
- Selected file cards
- Remove selected files

## Current Limit

Maximum individual file size:
50 MB

- Improved error notifications
- File reordering
